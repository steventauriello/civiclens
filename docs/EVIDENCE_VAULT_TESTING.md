# Evidence Vault Preview Test Checklist

Use this checklist before merging the current Evidence Vault pull request.

- Open the Netlify Deploy Preview.
- Confirm the Evidence Vault is reachable from the main CivicLens dashboard.
- Confirm the upload dialog fits on desktop and mobile.
- Confirm PDF preview rendering works.
- Confirm the storage status tile reports the configured backend state.
- Unlock permanent storage with the admin credential.
- Upload or migrate a test document.
- Refresh the page and confirm the permanent record remains available.
- Open the preview from a second device and confirm the permanent record is visible there after unlocking storage.
- Confirm the original document remains private and is accessed only through the vault workflow.
