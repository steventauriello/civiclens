# Frontend

The public and administrative web interfaces will live here.

Initial public capabilities:

- Natural-language search
- Guided resident questions
- Revenue and spending explorer
- Property-tax explainer
- Fund, department, project, vendor, and contract pages
- AEN Review pages
- Show the Evidence drawer
- Data-quality and correction notices

No framework has been initialized yet. The reference architecture currently favors Next.js and TypeScript, subject to an architecture decision record.
