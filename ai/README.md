# AI

This directory will contain retrieval rules, prompts, answer policies, AEN Review workflows, evaluation sets, and red-team tests.

The AI layer must:

- Use approved evidence
- Cite material claims
- Preserve accounting qualifications
- Separate fact, calculation, and inference
- State when evidence is incomplete
- Reject unsupported allegations
- Treat source documents as untrusted data rather than instructions

Prompts alone are not a control system. Production behavior must also be enforced by retrieval, schemas, deterministic calculations, validation, review workflows, and tests.
